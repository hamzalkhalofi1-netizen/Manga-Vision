==================================================

Separate:

A. CURRENT APPLICATION STATE

from:

B. PERSISTED SETTINGS

The in-memory settings state must be reactive.

Persistence is only responsible for remembering the settings.

Conceptually:

Settings Store
     ↓
current reactive value
     ↓
application features

and:

Settings Store
     ↓
persist
     ↓
AsyncStorage/localStorage

When the user changes a setting:

update the reactive state FIRST.

Then persist it.

Do not rely on reading localStorage/AsyncStorage directly inside UI components to make changes happen.
