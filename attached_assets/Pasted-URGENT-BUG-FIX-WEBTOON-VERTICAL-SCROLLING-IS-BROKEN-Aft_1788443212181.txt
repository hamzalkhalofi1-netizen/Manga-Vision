URGENT BUG FIX — WEBTOON VERTICAL SCROLLING IS BROKEN

After the latest Settings / Reader updates, the Webtoon reading mode has a critical regression.

CURRENT PROBLEM:

When opening a manga/manhwa in WEBTOON / LONG VERTICAL READING MODE:

- I can see the manga pages/images.
- The images are displayed.
- Translation can work.
- BUT I CANNOT SWIPE UP OR DOWN.
- Vertical scrolling is completely blocked or does not respond to touch.

This worked before the latest changes.

DO NOT redesign the reader.

DO NOT remove existing translation functionality.

DO NOT remove the Webtoon mode.

Find the regression and restore natural vertical touch scrolling.

4. CHECK SCROLLVIEW CONFIGURATION
==================================================

If the reader uses React Native ScrollView, verify:

- scrollEnabled is true
- vertical scrolling is enabled

- parent containers provide bounded height
- flex: 1 is correctly propagated

- no child is incorrectly claiming the touch responder

Do not add arbitrary fixed heights.

The ScrollView must occupy the available reader viewport correctly.

5. CHECK FOR TOUCH BLOCKING OVERLAYS
==================================================

THIS IS VERY IMPORTANT.

Inspect every absolute-positioned layer above the manga.

Especially:

- translation overlays
- text overlays
- transparent containers
- page controls
- header
- bottom controls
- chapter controls
- loading overlays
- gesture layers
- invisible hitboxes
- settings overlays

Look for:

pointerEvents

onTouchMove

onStartShouldSetResponder

PanResponder
GestureDetector
Pressable

absoluteFill
zIndex

A transparent/full-screen View can completely block scrolling even if it has no visible content.

Do NOT allow invisible overlays to capture the entire screen.

Use appropriate pointer event behavior.

For example, decorative/non-interactive overlays should generally allow touches to pass through rather than intercepting the Webtoon scroll.

==================================================
6. TRANSLATION OVERLAY MUST NOT BLOCK SCROLLING
==================================================

The translated text layer is especially important.

The user must be able to swipe directly over:

- translated text

- images

Text overlays should NOT steal vertical swipe gestures.

If the translation overlay is only visual:

make it non-touch-blocking.

If certain buttons need interaction:

only those specific buttons should receive touches.

Do NOT make the entire translation layer interactive.

On Android, WebView nested scrolling behavior can differ from a normal React Native ScrollView, so do not blindly wrap WebView in another ScrollView.

The goal is to establish ONE correct scrolling owner.
